Python SDK

The EvalHub Python SDK provides synchronous and asynchronous clients for the EvalHub REST API, plus an adapter framework for building evaluation integrations.

Installation

Section titled “Installation”

Note

The [server] extra installs the eval-hub-server binary for local/embedded use. It is deliberately excluded from [all] due to its size (~20 MB).

Agent discoverability

Section titled “Agent discoverability”

Providers and benchmarks may include an optional agent metadata block returned by the API. Use it to discover evaluations by capability, read operational hints, and interpret results.

See Agent Discoverability for the full metadata model.

  • Synchronous
  • Asynchronous

Note

client.providers.list(target_type=, evaluates=) fetches all providers then filters client-side. The CLI evalhub providers list does not expose filter flags yet. Collection agent metadata is available via REST and MCP but not yet modeled on the SDK Collection type.

ModelDescription
